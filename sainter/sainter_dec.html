Private, in-browser utility

Decode & Decrypt

Decode Base64 text or files, or decrypt AES-GCM data with its original passphrase.

Operation

Base64 decoding reverses encoding; it does not decrypt or protect data.

Paste encoded data
File selection replaces the text input.

Use the same passphrase that was used to encrypt this data.

Text appears here; files can be downloaded

How to use: Paste a Base64 result, choose Base64 to decode or AES-GCM to decrypt, then enter the passphrase if requested. Files encoded by the encoder retain their name and type and can be downloaded here.
Privacy: All processing stays in this browser; nothing is uploaded. AES requires Web Crypto in a secure context, typically HTTPS or localhost. If opened as a local file, AES may be unavailable in some browsers.
